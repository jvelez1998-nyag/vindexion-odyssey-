# Canonical Definition

RSK-082 enables the RCSA program to learn from enterprise assessment outcomes and propose or execute bounded changes to:

```text
CAMPAIGN SCOPE
      +
ASSESSMENT FREQUENCY
      +
QUESTION DEPTH
```

based on where material risk is actually emerging.

The capability moves RCSA from:

```text
STATIC PROGRAM DESIGN
      ↓
PERIODIC HUMAN REVIEW
      ↓
NEXT CAMPAIGN
```

toward:

```text
ASSESS
      ↓
OBSERVE OUTCOMES
      ↓
LEARN PATTERNS
      ↓
ADAPT PROGRAM
      ↓
ASSESS AGAIN
```

within explicit human-defined operating boundaries.

# Core Product Thesis

# **THE RCSA PROGRAM SHOULD LEARN FROM WHAT ITS OWN ASSESSMENTS KEEP DISCOVERING.**

Traditional programs often maintain:

- Fixed annual calendars
- Uniform assessment frequencies
- Standardized question depth
- Broad recurring scope

even when historical evidence shows that risk is not distributed uniformly.

RSK-082 asks:

```text
WHERE DOES MATERIAL RISK
ACTUALLY KEEP APPEARING?
```

and then:

```text
SHOULD THE PROGRAM
CHANGE HOW IT ASSESSES
THAT PART OF THE ENTERPRISE?
```
